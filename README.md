# Admission Process Automation

## Project Overview
Admission Process Automation is a full-stack web application designed to simplify and automate the college admission process. It provides a centralized platform where students can register, submit admission applications, upload documents, track application status, and receive admission updates.

The system also provides an admin dashboard for managing applications, verifying documents, and updating admission statuses.

## Objectives
- Simplify the college admission process.
- Reduce paperwork and manual work.
- Allow students to apply online.
- Provide real-time application status tracking.
- Help administrators manage applications efficiently.

## Key Features

### Student Module
- Student registration and login.
- Browse available courses.
- Online admission application.
- Upload required documents.
- Track application status.
- View admission notifications.

### Admin Module
- Secure admin login.
- View and manage student applications.
- Verify uploaded documents.
- Approve or reject applications.
- Manage courses and admission details.
- Dashboard with application statistics.
